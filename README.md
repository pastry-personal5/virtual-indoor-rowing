# Virtual Indoor Rowing

An offline-capable virtual rowing application for Apple-silicon Macs, initially for a Concept2 Model D with PM5 over BLE.

Start with [architecture](ARCHITECTURE.md), then [contributing](CONTRIBUTING.md) and the [development guide](DEVELOPMENT.md). Detailed specifications, ADRs, phase-scoped milestones, and research are indexed in [docs](docs/README.md).

This repository is architecture-first. Phase 1 is complete: the internal macOS build has PM5/simulator workout input, durable local sessions, a live HUD, and gray-box course presentation. It remains an unsigned, ad-hoc internal build rather than a production release. [Phase 2](docs/phase-2/README.md) is planned and has not started.
