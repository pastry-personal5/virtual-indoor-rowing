# Delivery Phase 1 changelog

This document records changes to the milestones that contribute to delivery Phase 1. It does not assert completion of the delivery Phase 1 exit gate.

## Unreleased

### Added

- Scoped and implemented Phase 1 Milestone 4 (`WorkoutRuntime` live session loop). Owner-confirmed scoping (2026-09-19): an engine-independent Just Row orchestrator with a synchronous `IJournalSink` seam and a pull snapshot API; the Unreal HUD is deferred to Milestone 5; device `Complete`/`Terminated` end a session; `pm5-tui` is the driver; real-PM5 confirmation is non-blocking. Delivered: `Source/WorkoutRuntime` (`FWorkoutSession`, `FWorkoutSnapshot`, `IJournalSink` and its `LocalData` adapter) with `workout_runtime_tests`; `session_summary.proto` and `LinkGapRecorded`; additive `RowingCore` state reasons `DeviceCompleted`/`DeviceTerminated`/`ReconnectWindowElapsed`; additive `LocalData` journal-event kinds `CapabilityObserved`/`LinkGap` and `RecordCapabilityObserved`; `pm5-sim` `MakeDeviceCompletedFixture`/`MakeDeviceTerminatedFixture`; and the opt-in `pm5-tui --journal` driver (`make pm5-tui-journal`). Simulator evidence only. See [04-milestone-4-workout-runtime.md](04-milestone-4-workout-runtime.md), including its implementation notes.
- Scoped and implemented Phase 1 Milestone 3 (build-order step 4: "SQLite journal/chunks/recovery/outbox"). Owner-confirmed scoping (2026-09-18): full nine-table schema, AES-256-GCM/Keychain encryption at rest, `DeviceCapabilityObserved`/`MetricSampled` wire mapping deferred from Milestone 2, and explicitly no live `RowingDevice`→`LocalData` capture loop. Delivered: schema version 2 with a v1→v2 migration (`local_data_schema_migrates_v1_journal_without_data_loss`); `Contracts/proto/rowing/v1/telemetry.proto` and a private domain↔wire mapper (`local_data_wire_mapping_tests`); the `IBlobCipher` seam with sealed sample chunks and session summaries, `CreateSession`/`UpdateSessionState`/two-phase summary write and their readers; and the Apple-only `LocalDataMac` module (CryptoKit AES-256-GCM through a Swift C-ABI shim, Keychain-held data key; `local_data_mac_tests`). The Swift shim is the repository's first Swift code and needed no new pinned tool (Xcode's `swiftc`). See [03-milestone-3-local-data-session-journal.md](03-milestone-3-local-data-session-journal.md), including its implementation notes.
- Scoped and implemented Phase 1 Milestone 2 (build-order step 3: "PM simulator, protocol codec, CoreBluetooth adapter, capability handshake"). Owner-confirmed scoping (2026-09-18): promote the existing Phase 0 diagnostic-grade `IRowingMachine`/`Concept2PMDiscoveryMac`/`Tools/pm5-sim` foundation rather than build a parallel implementation; defer telemetry/capability Protobuf wire mapping to Milestone 3; keep CSAFE managed-workout control diagnostic-only (Phase 2 territory). During implementation, found the reviewed non-diagnostic product profile and its factory wiring already existed from Phase 0 (`Concept2PM::GetGeneratedPM5CapabilityProfiles()`), so the milestone's actual code change narrowed to a new `pm5_reviewed_profile_tests` CTest target (`Tests/Contract/pm5_reviewed_profile_tests.cpp`) exercising acceptance/rejection against the real generated profile set. Real-PM5 confirmation run remains outstanding (owner-run). See [02-milestone-2-device-capability-handshake.md](02-milestone-2-device-capability-handshake.md).

### Fixed

- Phase 1 Milestone 3 second review pass: one `FSqliteConnection::InTransaction` helper replaces five hand-copied begin/commit/rollback blocks (recovery's `DeleteChunk` had been missed and could leave a transaction open); a failed `COMMIT` on a staged chunk/event/summary now keeps the stage so the caller can retry; `ScanAndRecover` examines every session in `journal_events` (not just the last with chunks) and ends a `sessions` row whose terminal event committed before a crash; `UpdateSessionState` rejects leaving `Ended`; journal-event payloads are sealed when a cipher is configured; `sessions` matching in recovery is a direct parsed-id `UPDATE` instead of a full scan; `FCryptoKitBlobCipher` zeroes its key on destruction and the Swift shim no longer copies the key through `Data`.
- Phase 1 Milestone 3 review findings: writer transactions now roll back on failure (a failed `Seal` previously wedged the writer); the Keychain create-race retry is bounded; schema migrations are race-safe with a busy timeout; `ReadSampleChunks` with a cipher rejects plaintext/unknown codecs; `session_summaries`/`cloud_links` reference `sessions`; `ScanAndRecover` ends the open `sessions` row; the CryptoKit end-to-end test now covers summaries.

### Changed

- `CLAUDE.md` module boundaries and repository layout now describe the full `LocalData` schema and the new `LocalDataMac` module.
- Deferred the design-partner cohort from Phase 1's exit gate to Phase 4's, per [ADR-0011](../adr/0011-defer-design-partner-cohort-to-phase-4.md): named-partner recruitment is not feasible on the current timeline, so it can no longer be a hard condition of closing Phase 1. Updated in [the delivery plan](../architecture/10-delivery-plan.md) and this packet's README; ADR-0010's design-partner disposition is superseded accordingly.

### Added

- Opened delivery Phase 1 packet (`docs/phase-1/README.md`) per [ADR-0010](../adr/0010-defer-remaining-phase-0-spike-evidence-to-phase-4.md), following delivery Phase 0's revised exit gate. No milestone scoped or started yet.
- Phase 1 Milestone 1 (build-order step 2): a real, non-diagnostic `RowingCore` session-continuity domain (`FRowingSessionId` UUIDv7, `ERowingSessionState`/`ERowingSessionDisposition`/`ERowingSessionStateReason`, `FRowingSessionStateMachine`) and its Protobuf contract seed (`Contracts/proto/rowing/v1/session.proto`, `SessionStateChangedEvent`). New behavioral tests: `rowing_session_state_machine_tests`, `rowing_session_contract_tests`. See [01-milestone-1-rowingcore-domain-contract.md](01-milestone-1-rowingcore-domain-contract.md).
- Pinned the Protobuf toolchain (`protobuf 36.1`) in `Config/BuildVersions.json` and `make doctor`, matching the existing `cmake`/`ninja`/`git_lfs` exact-version pattern. `protobuf 36.1` was installed via `brew install protobuf`, which also pulled in `abseil 20260817.0` as a transitive dependency; abseil itself is not independently pinned or checked by `make doctor`. New CMake target `RowingContracts` generates and builds the Protobuf contract code; nothing depends on it yet.

Full 60-minute latency/durability evidence remains open as later follow-on. Updated in [the delivery plan](../architecture/10-delivery-plan.md) and this packet's README.
